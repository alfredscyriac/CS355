### Topic 4 - OSI & TCP/IP Model: 
- Both OSI and TCP/IP are **conceptual** models built around the notion of layering 
- The OSI model has 7 layers
- The TCP/IP model has both 4 and 5 layer variants 
- A protocol is a system of rules that allows two or more entities to transmit or receive information. These rules deteremine all aspects of data communication including syntax, semantics, sychronization, and error recovery methods 
- Historical comminications protocols go way back before computers. The earliest recorded usage of them trace back to 776 BC during the first olympics with homing pigeons
- **Unidirectionality** means that messages can only be sent in one direction (i.e. from A to B but NEVER from B back to A)
- Transmission Medium vs Communications Protocol: 
  - In the hydraulic semaphore example, the transmission medium is simply the light emitted from the torch, the protocol however includes all the other contraptions and coordinations between both entities in order to send and receive the message 
  - You can think of a protocol as a distributed algorithm in which multiple parties work together to faciliate message exchange 
- Computer protocols are extremely strict and when writing the specification of one there can be no ambiguity 
- Open Systems Interconnected Model:
    - Layer 7 - Application
    - Layer 6 - Presentation 
    - Layer 5 - Session 
    - Layer 4 - Transport 
    - Layer 3 - Network -> Provided end-to-end trasport of data 
    - Layer 2 - Data Link -> encoding information from a computing device onto a communications medium and transmitting data from one network device to the next. **Only facilitates transported data across a single hop**
    - Layer 1 - Physical -> how information is encoded 
- TCP/IP Model (5-layer variant):
  - Layer 5 - Application 
  - Layer 4 - Transport 
  - Layer 3 - Network 
  - Layer 2 - Data Link 
  - Layer 1 - Physical -> removed in the 4 layer variant 
  > this is the model that is used in the modern day
